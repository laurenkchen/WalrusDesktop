# Walrus Desktop

## Usage
+ Walrus doodle runs across your screen like the little DVD player icon thingy!
+ You can change the speed at which the walrus moves
+ And ask for wisdom from the walrus!
+ The walrus gets sleepy when he stops moving (be warned)

+ Do not question the anatomical structure of the walrus.
